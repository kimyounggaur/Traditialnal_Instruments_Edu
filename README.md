# 국악의 서재 · 레슨 디자이너

첨부 설계서 P00–P11과 책장형 홈 부록을 바탕으로 구현한 **한국어 로컬 시연 전자도서관**입니다. 따뜻한 종이색 책장, 14개 자료군 탐색, 구조화 단원 읽기, 북마크·이어읽기, 수업안 편집/인쇄, 원자료 관리, 검수·권리·판본 흐름을 제공합니다.

## 처음 실행하기

1. 이 ZIP을 압축 해제합니다. Windows에서는 다운로드 폴더 안의 ZIP을 연 상태로 실행하지 말고 먼저 ‘모두 압축 풀기’를 선택하세요.
2. Node.js 22 이상을 설치합니다. 설치된 경우 건너뜁니다.
3. Windows: `start-windows.cmd`를 실행합니다. 최초 실행 시 필요한 패키지를 설치합니다.
4. 브라우저에서 **http://localhost:3000** 을 엽니다. 종료할 때 실행 창에서 Ctrl+C를 누릅니다.

macOS/Linux 또는 터미널에서 직접 실행:

```bash
npm ci
npm run dev
```

배포 없이 로컬 production 빌드 실행:

```bash
npm run build
npm start
```

이 앱은 계정·서버 데이터베이스가 없으며, 처음 실행에 패키지 설치 인터넷 접속이 필요합니다. 앱 자체는 외부 AI·분석 SDK·카메라·마이크·학생정보를 사용하지 않습니다.

## 먼저 확인할 화면

- `/`: 타이포그래피 표지 책장과 목록 대안, 14개 자료군, 검색·필터, 이어읽기.
- `/library`: 검색어와 필터가 주소에 저장되는 서고. ‘실자료 공개 보기’는 0건입니다.
- `/library/demo-gayageum`: 출처·판본·권리·악기형과 단원.
- `/teacher/plans`: 합성 40분 수업안 14개, 작성·복제·저장·인쇄.
- `/practice`: 연습 앱 후보 상태. 확인되지 않은 후보는 실행되지 않습니다.
- `/admin/sources`: 실제 원본 PPTX 14파일·702슬라이드의 메타데이터.
- `/admin/resources`, `/admin/apps`, `/admin/reviews/demo-gayageum`, `/admin/issues`: 편집과 검수 흐름 시연.

상단 역할 선택은 **가상 역할 시연**입니다. 실제 사용자 인증·보안 권한이 아닙니다.

원자료 PPTX와 추출 본문은 이 앱에 포함하지 않습니다. 파일 메타데이터와 위치 증거만 추적합니다. 표지와 중립 문구는 합성 UI 시연이며, 운지·조율·음역·악보·교수법의 정확성을 인증하지 않습니다. 실제 승인 레슨과 합성 자료를 합산하지 않습니다.

## 저장·백업·복구

브라우저 `gugak-library:v1` 저장소에 북마크, 읽던 판본/단원, 교안, 편집·검수 이력을 저장합니다. 다른 기기·브라우저로 자동 동기화되지 않습니다. 클래식 프로젝트의 키는 읽거나 변경하지 않습니다.

관리 화면의 JSON 백업은 허용된 시연 자료 메타데이터와 교안만 내보냅니다. 다운로드 권리가 없는 원문·단원 본문은 제외됩니다. 가져오기 전에 유효성·용량·외래키·충돌을 검사하고, 실제 원자료나 승인 판본을 덮어쓰지 않습니다. 손상·저장 차단·용량초과 시 경고와 메모리 모드가 표시되므로 브라우저를 닫기 전에 백업하세요. 초기화는 확인 후 진행합니다.

## 검사

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

브라우저 E2E를 사용자 환경에서 실행하려면:

```bash
npx playwright install chromium
npm run test:e2e
```

실행한 검사와 미실행 검사는 `docs/TEST_REPORT.md`에 분리해 기록합니다. 브라우저 E2E·시각·인쇄 미리보기는 별도 실제 검증이 필요합니다. 자동 검사 통과는 음악 내용의 전문 검수를 의미하지 않습니다.

## 이어서 개발하기

`PROMPT_PACK.md`를 먼저 읽고 `docs/STATUS.md`, `docs/TEST_REPORT.md`, `docs/HANDOFF.md`를 확인합니다. 기존 저장키·원자료 메타데이터·승인 판본을 보존하세요. 원본 텍스트 추출기는 `scripts/extract_pptx.py`이며 압축 폭탄·경로 이탈·외부 엔티티·매크로를 거부합니다.

실제 콘텐츠 공개는 음악 전문가와 권리 책임자의 검토 증거가 필요합니다. 공개 배포·Git push·계정/DB 생성·유료서비스는 이번 로컬 구현에서 수행하지 않았습니다.
