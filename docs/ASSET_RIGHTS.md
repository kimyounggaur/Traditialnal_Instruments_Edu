모든 실제 source 권리 state는 unknown이고 holder/license/evidenceRef/checkedBy는 null이다. 열람·인쇄·다운로드·재배포 허용을 AI가 생성하지 않는다. 프로그램이 추출한 링크와 이미지 참조를 자동으로 다운로드/실행하지 않는다.

합성 단원은 실제 운지·조율·장단 정답을 제공하는 교재가 아니다. 검수된 설명을 넣을 자리, 자료 출처 확인, 중립 체크리스트 등으로 명시한다. 가상 검수자의 승인 흐름도 실교육 승인을 뜻하지 않는다.

실자료 도입 순서: 파일별 저작권자/라이선스/허용 행위와 증거 확인 → 이미지·악보·음원 하위권리 확인 → 음악/교육/안전 검수 → 정확한 판본 승인 → 서버 접근·공개 정책 확인. 권리 제한 자산은 출력·다운로드 실제 명령에서도 제외한다.
