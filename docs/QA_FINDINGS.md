## 대비와 반응형의 확인 한계

WCAG 상대 휘도 계산식으로 최종 CSS에 지정된 기본 색상 쌍을 계산했습니다. 아래는 불투명 단색의 수치이며, 실제 합성 화면·안티앨리어싱·포커스·모든 상태를 검증한 것이 아닙니다.

| 표지 크림 `#fff6e7` / 양금 `#795725` | 6.12:1 |
| 표지 크림 `#fff6e7` / 태평소 `#865726` | 5.75:1 |

## 작성했으나 실행하지 않은 Playwright 시나리오

28개: 14자료군 각각의 책장→상세→단원→새 40분 수업안, public 우회 차단, 검색과 초기화, 전체 필터 복귀, 북마크/읽기 위치 재시작, 주요 오류 신고 후 보류, native dialog의 Tab/Shift+Tab/Enter/Escape와 포커스 복귀, 손상 저장값 복구, 외부 서비스 및 카메라·마이크 요청 없음, 5종 화면 폭, 200% 글자 크기 확대 대리 검사.

`200% text-resize proxy`는 CSS 글자 크기를 2배로 하는 검사입니다. 브라우저의 실제 200% 페이지 확대와 동일하다고 간주하지 않습니다. 실제 확대와 인쇄 미리보기, 스크린리더, 교육용 이미지의 충분한 대체 설명, 원본/PDF 시각검사는 별도로 남아 있습니다.

사용자 로컬 환경의 재현 명령:

```sh
npm install
npx playwright install chromium
npm run test:e2e
```

실제 실행 전에는 E2E 통과, 모바일 완성, 접근성 인증 또는 인쇄 화면 검증 완료로 표시하면 안 됩니다. 외부 앱 네트워크 접속은 E2E의 전제 조건이 아닙니다.
