# 인수 안내

이 프로젝트는 별도 국악 전자도서관 로컬 프로토타입이다. 실행 가능한 화면과 검사 결과는 최종 README.md, STATUS.md, TEST_REPORT.md에서 확인한다. 아래 명령은 package.json에 정의된 실행 경로이다.

브라우저 실화면 확인, Playwright E2E 실행, 인쇄 미리보기 검사는 이번 환경에서 미실행이다. 아래 실행법과 DEMO_SCRIPT.md는 다음 확인을 위한 절차이며, 화면·키보드·모바일·200% 확대·인쇄가 검증됐다는 증거가 아니다.

## 처음 실행

1. Node.js 환경에서 프로젝트 폴더를 연다.
2. npm ci로 package-lock.json의 버전을 설치한다.
3. npm run dev를 실행하고 http://localhost:3000 을 연다.
4. 합성 데모 책장 → 책 열기 → 단원 → 수업안 순서로 확인한다.
5. 종료는 터미널에서 Ctrl+C. 다시 실행해도 같은 브라우저의 로컬 기록은 남는다.

검사 명령: npm run lint, npm run typecheck, npm test, npm run test:e2e, npm run build. production 확인은 npm run build 이후 npm start. Playwright 브라우저가 없는 환경은 npx playwright install chromium이 필요할 수 있다. 실행하지 않은 명령을 통과로 보지 않는다.

## 데이터와 초기화

저장은 현재 브라우저의 gugak-library:v1에만 있다. 다른 기기·브라우저·시크릿창으로 자동 동기화되지 않으며 브라우저 데이터 삭제 시 사라진다. 제공된 초기화 버튼은 확인 후 이 프로젝트 키만 초기화한다. 저장차단/용량초과 시 화면 경고와 메모리 작업을 구분한다. 작업 중에는 내보내기 가능 데이터만 보관하고 교안·편집본에 실학생 정보를 쓰지 않는다.

## 실제 자료와 시연 자료

실제 원자료는 14개 PPTX·175,327,482 bytes, 안전 XML 추출은 702슬라이드이다. source metadata의 해시는 SOURCE_MANIFEST.json에 있다. 앱에 탑재된 실제 원문·실제 단원 본문은 0개이며, 추출한 원문/원본은 앱 및 배포용 ZIP에서 제외한다. 실제 PDF는 0개, 실제 승인 레슨0, 공개 활성 앱0이다.

합성 fixture는 자료14/단원28/40분 교안14이며 실제 국악 교재 완성과 합산하지 않는다. 원문 목차의 명시 범위에 따른 25개 편집 묶음 후보는 문서 제안이고 실제 채택 단원 수와 다르다. 실제 원문과 편집본 대조는 권리 검토 후 별도 비공개 편집 환경에서 이어간다.

## 구현한 교사·관리자 기능

- 교사 화면: 교안 목록·검색·새 교안·복제·삭제 확인, 활동 편집·순서 변경·시간 검증·자료판본 고정, 저장·충돌/미저장 안내, 권리를 검사한 인쇄용 내용 구성. 실제 인쇄 미리보기는 미확인이다.
- 관리자 화면: 원자료 인벤토리, 합성 자료 편집과 판본·검수 절차 시연, 실제 원자료의 메타데이터 초안 편집, 앱 후보와 점검 근거 편집, 오류 신고 처리, 합성 백업/가져오기/초기화. 실제 원자료 편집은 메타데이터와 권리 검토 메모 범위이며 원본 파일·추출 원문·실제 승인·공개 상태를 바꾸지 않는다.

위 기능의 코드 구현과 브라우저에서 끝까지 조작한 검증은 구분한다. 실제 실행한 자동 검사와 남은 검사 결과는 TEST_REPORT.md를 따른다.
