# 구현 계약 · 레슨 디자이너 국악기 교육 전자도서관

기준: PROMPT_PACK.md v1.0, 2026-10-14. 이 문서는 구현 요구사항이다. 실제 통과 여부는 STATUS.md와 TEST_REPORT.md가 우선한다.

## 범위와 수량

별도 gugak-library 프로젝트의 한국어 로컬 시연이다. 클래식 파일·데이터·배포 주소와 저장키를 변경하지 않는다. 익명 학생·교사·검수자·편집 관리자 역할은 화면 시연이며 실계정 인증이 아니다. 실제 교재 본문은 정적 앱 번들에 넣지 않는다.

| 항목 | 확인 수량/상태 | 해석 |
|---|---:|---|
| 실제 원자료 | PPTX 14파일 | PDF 14권이 아님 |
| 주 탐색 자료군 | 14 | 타악기·사물놀이 묶음 포함 |
| XML 텍스트 추출 | 14파일, 702슬라이드 | OCR·시각·교육 검증 아님 |
| 앱에 탑재한 원자료 본문 | 0 | 메타데이터만 제공 |
| 실제 채택 편집 단원 | 미확정 | 별도 목차 기반 후보는 승인 아님 |
| 실제 승인 레슨 | 0 | 실제 승인 증거 없음 |
| 공개 활성 앱 | 0 | 후보도 실행·호환성·개인정보 검증 전 비활성 |
| 합성 시연 목표 | 자료14 / 단원28 / 교안14 | 실제 교재 실적과 분리 |

P0에 검색·뷰어·북마크·교안·편집·검수·권리·판본·신고·로컬 저장·인쇄·접근성·자동 검사를 포함한다. 실제 계정, 외부 DB, 공동편집, 학생 데이터, 카메라·마이크, 외부 AI, API/SSO, 진도 동기화, 공개 배포는 이번 구현 범위 밖이다.

## 자료군 사전

gayageum 가야금, geomungo 거문고, daegeum 대금, danso 단소, saenghwang 생황, sogeum 소금, ajaeng 아쟁, yanggeum 양금, janggu 장구, cheolhyeongeum 철현금, taepyeongso 태평소, piri 피리, percussion-samulnori 타악기·사물놀이, haegeum 해금. 현악/관악/타악/묶음은 탐색용 분류이며 학술 분류를 대체하지 않는다. 양금은 타현이라는 이유로 현악 속성을 삭제하지 않는다.

## 재사용과 국악 변경

재사용: repository 경계, 검색/필터, 판본 고정, 저장 복구, 교안, 권리별 출력, 검수 상태기계, 회귀검사 패턴.
국악 변경: 고유 14자료군, 악기형 nullable, 장단 문맥, 기보/정간 방향, source slide 추적, XML 안전 추출, 실제 승인0/앱0. 클래식 데이터·악기 수·앱 주소를 문자열 치환하지 않는다.
