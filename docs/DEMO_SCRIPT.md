# 5분 시연 대본

목적은 교사의 자료 찾기·읽기·수업 준비 흐름과 공개 차단을 설명하는 것이다. 실제 교재의 교육 정확성을 시연으로 승인하지 않는다.

이 대본은 구현된 기능을 다음 브라우저 확인에서 따라갈 절차다. 브라우저 실화면, E2E, 인쇄 미리보기는 미실행이므로 아래 동작/기대값을 실제 확인 완료로 읽지 않는다. 실행 증거는 TEST_REPORT.md에 별도로 남긴다.

| 시간 | 조작 | 말할 내용/확인 |
|---|---|---|
| 0:00–0:35 | 홈에서 시연 배너·자료군·통계 확인, 책장/목록 전환 | 실제 PPTX14, 추출702슬라이드, 앱의 실제 원문/단원본문0, 실제 승인0·활성앱0. 화면 책은 합성 시연. |
| 0:35–1:05 | 가야금 필터·검색, 정렬 후 책 열기 | 검색/필터가 URL에 남고 책장/목록 데이터가 같다. 타악기·사물놀이는 묶음. |
| 1:05–1:45 | 출처/판본/미확인 악기형을 읽고 단원 이동·북마크 | 실제 PDF 준비 중, 구조화 단원이다. 원본 슬라이드와 편집단원을 혼동하지 않는다. |
| 1:45–2:10 | 새로고침하고 이어읽기 | 같은 resource/version/asset/unit로 복원되는지 확인한다. 실제 PDF3쪽 복원은 PDF가 없어 이번 시연 대상 아님. |
| 2:10–3:00 | 교안 담기/편집, 활동 시간 변경 후 저장·복제 | 기본 합성40분=5+10+15+10. 합계가 다르면 안내한다. 자료판본은 고정. |
| 3:00–3:25 | 연습실 열기 후 원래 단원으로 복귀 | 앱 후보는 준비 중/비활성. 앱 주소 존재만으로 모델·안전 검증을 주장하지 않는다. |
| 3:25–3:55 | 저장한 교안에서 인쇄 미리보기 열기 | 구현된 권리 검사와 인쇄용 내용을 바탕으로 시연 배지·출처·판본·권리표시 및 제한 자료 제외를 확인한다. 실제 인쇄 결과는 아직 미검증. |
| 3:55–4:25 | 단원의 오류 신고, 위치/심각도 입력 | 이름·학교·이메일 없이 신고한다. 중대/안전 신고는 자료 보류와 교안 경고로 연결. |
| 4:25–5:00 | 편집 관리자에서 실제 원자료 메타데이터 초안 편집, 합성 검수 절차·실제 공개 보기0건 확인 | 원본 PPTX와 추출 원문은 불변이다. 실제 자료의 승인·공개는 잠겨 있으며 합성 승인 흐름만 시연한다. 가상 역할은 실보안이 아니다. |

시험 데이터 변화로 기존 합성 책이 보류되면 다른 합성 책으로 이어간다. 초기화가 필요하면 확인 버튼으로 해당 국악 데이터만 초기화하고 취소가 보존되는지도 확인한다. 실제로 구현되지 않은 버튼/연결은 정상 동작처럼 설명하지 않고 TEST_REPORT의 제한을 읽는다.
